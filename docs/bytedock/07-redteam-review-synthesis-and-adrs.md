## 三、三轮评审终裁总表（12/12 ADR 全部闭合 → Go for R4）

- **R1 + Opus 5.5 清除的 8 项宏观缺陷**：同契约非同构（F1）、Revision Pinning（F2）、`plugins.invoke` 命名空间白名单与配置移出 `ServerSettings`（F3）、CacheGuard 反转（F4）、排期去乐观化为 4–8 周 v0.1-lite（F5）、`StreamLog` 增量分频、诚实三级 Egress 口径、接缝盘点补全与 Radar 防漂移。
- **R2 终裁的 4 大分歧与 5 项机制补正**：D1 判死 `worker_thread`、D2 判 NapCatQQ Bot 胜出、D3 锁定 12 必切 / 4 延迟接缝、D4 锁定四格存储 + 三通道热同步；CacheGuard 适配有状态 CLI 双轨化、Pin 补 idle/forceReap/单 lane、`EgressProof` 双段化、v0.1 禁插件互调、CI 一次过约束。
- **R3 拆解的 0 号打包核弹与 6 大极限靶心**：**0 号核弹终裁方案 α（`HostModuleRegistry` + `vm.compileFunction` 宿主内存注入，彻底免疫 `vp pack`/SEA 内联 `effect` 陷阱）**；修复 `drainDeadline` 锚 `installedAt` 致命 Bug 改 `frozenAt` + `ThreadSessionGate` + `drainInFlightMs` + 单调寿命 touch；补 `profileKey` 三元组 + `outboundUserText` 隔离气泡 + per-session `list_changed`；补 Dispatcher 双闸 + 双层 DNS/SSRF + 三句诚实措辞模板；新建 `PluginSandboxFrame` 移除 `allow-forms` + pending 队列 nonce；12 原语宿主化于 `apps/web/src/components/plugin/` 并删 `StatRow` 并入 `Card.kpi`；确立双 tag `check-seams.ts` 协议与 R4 10 章 Go 蓝图结构。
